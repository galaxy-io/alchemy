# Alchemy TypeScript SDK

Create functions, ship versions and invoke them from TypeScript or JavaScript.

- **Package:** `@galaxy-io/alchemy-ts`
- **Import:** `import { AlchemyClient } from "@galaxy-io/alchemy-ts"`
- **Node:** 18+, or any runtime with `fetch`
- **Module format:** ES modules with bundled type declarations

## Installation

~~~sh
npm install @galaxy-io/alchemy-ts
~~~

## Connect to Alchemy

~~~ts
import { AlchemyClient } from "@galaxy-io/alchemy-ts";

const alchemy = new AlchemyClient({
  baseUrl: process.env.ALCHEMY_URL ?? "http://localhost:8780",
  auth: false,
});

const { functions } = await alchemy.function.list({});
for (const fn of functions ?? []) {
  console.log(fn.id, fn.name);
}
~~~

This connects to a server with authentication disabled. See
[Authentication](#authentication) for a deployed server.

Set request timeouts with `timeoutInSeconds` and retries with `maxRetries`,
on the client or per call. The client retries twice by default. Pass
`maxRetries: 0` on calls that must not repeat, such as an invoke without an
idempotency key.

## Authentication

When the server runs with an identity provider, the SDK authenticates as a
service account. Create one with `alchemy.serviceAccount.create(...)` while
signed in as an admin. It returns a client id and a client secret, and the
secret is shown once.

Pass them to the client. It mints an access token through the server and mints
again as the token nears expiry.

~~~ts
const alchemy = new AlchemyClient({
  baseUrl: process.env.ALCHEMY_URL ?? "http://localhost:8780",
  clientId: process.env.ALCHEMY_CLIENT_ID!,
  clientSecret: process.env.ALCHEMY_CLIENT_SECRET!,
});
~~~

A token minted elsewhere works as `token`. For a local server with
authentication disabled, pass `auth: false`.

## Invoke a function

`function.invoke` sends the input as JSON and resolves to the output, with no
envelope. It is for functions with a JSON Schema contract.

~~~ts
const output = await alchemy.function.invoke({
  function: "<function-id>",
  body: { id: "abc" },
});
~~~

`invocation.invoke` is the RPC form. It resolves to the invocation with its
id, status and error, and it carries the input and output as base64, which is
how an Arrow contract's IPC stream travels over JSON.

`invocation.invokeAsync` queues the call and resolves to its id at once. Read
the result later with `invocation.get`.

## API groups

| Group | Methods |
| --- | --- |
| `function` | `create`, `get`, `list`, `update`, `delete`, `invoke` |
| `function.version` | `create`, `get`, `list` |
| `invocation` | `invoke`, `invokeAsync`, `get`, `list` |
| `runtime` | `list` |
| `template` | `list` |
| `host` | `get`, `list` |
| `instance` | `list` |
| `metrics` | `queryTimeseries`, `queryAggregate`, `getQueue` |
| `auth` | `getConfig`, `getSession`, `login`, `logout` |
| `member` | `list`, `invite`, `setRole`, `remove` |
| `serviceAccount` | `create`, `list`, `rotateSecret`, `remove` |

`alchemy.getVersion({})` reports the server's build.

The SDK covers unary API methods. The streaming `GetInvocationLogs` and
`TailInvocations` are not included.

## Responses

Methods resolve to typed responses. For example, `function.create(...)`
resolves to an object whose `function` property holds the created function.

Fields the server omits are `undefined`, including lists. Use
`response.functions ?? []` when iterating. Protobuf 64-bit integer fields, such
as version numbers and timestamps, can be decimal strings. Use `Number(value)`
or `BigInt(value)` when needed.

Errors are thrown as `AlchemyError`, with `statusCode` and the server's
message. Timeouts throw `AlchemyTimeoutError`.

## Development

The client under `src/` is generated by Fern from the server's OpenAPI
specification. CI generates it. When the specification or `fern/` changes on
`main`, a workflow opens a pull request with the new `src/`. Do not edit or
commit that directory by hand. Configure names and generation in `fern/`.
