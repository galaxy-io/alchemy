# Alchemy Python SDK

Create functions, ship versions and invoke them from Python.

- **Package:** `alchemy-py`
- **Import:** `from alchemy import Alchemy`
- **Python:** 3.10+
- **Clients:** synchronous `Alchemy` and asynchronous `AsyncAlchemy`

## Installation

Install [alchemy-py from PyPI](https://pypi.org/project/alchemy-py/) with uv:

~~~sh
uv add alchemy-py
~~~

For an existing virtual environment, use `uv pip install alchemy-py`.

## Connect to Alchemy

~~~python
import os

from alchemy import Alchemy

alchemy = Alchemy(
    base_url=os.getenv("ALCHEMY_URL", "http://localhost:8780"),
    token=os.getenv("ALCHEMY_TOKEN", "local"),
)

for function in alchemy.function.list().functions or []:
    print(function.id, function.name)
~~~

The client always needs a credential. A server with authentication disabled
ignores it, so any placeholder works as `token` there. See
[Authentication](#authentication) for a deployed server.

Set request timeouts with `Alchemy(..., timeout=30)`. The value is in seconds.

## Authentication

When the server runs with an identity provider, the SDK authenticates as a
service account. Create one with `alchemy.service_account.create(...)` while
signed in as an admin. It returns a client id and a client secret, and the
secret is shown once.

Pass them to the client. It mints an access token through the server and mints
again as the token nears expiry.

~~~python
alchemy = Alchemy(
    base_url=os.getenv("ALCHEMY_URL", "http://localhost:8780"),
    client_id=os.getenv("ALCHEMY_CLIENT_ID"),
    client_secret=os.getenv("ALCHEMY_CLIENT_SECRET"),
)
~~~

A token minted elsewhere works as `token`.

## Invoke a function

`function.invoke` sends the input as JSON and returns the output, with no
envelope. It is for functions with a JSON Schema contract.

~~~python
output = alchemy.function.invoke(
    "<function-id>",
    request={"id": "abc"},
)
print(output)
~~~

Pass `version=3` to pin a version and `idempotency_key="..."` to make the call
safe to retry.

`invocation.invoke` is the RPC form. It returns the invocation with its id,
status and error, and it carries the input and output as base64, which is how
an Arrow contract's IPC stream travels over JSON.

~~~python
import base64
import json

response = alchemy.invocation.invoke(
    function_id="<function-id>",
    input=base64.b64encode(json.dumps({"id": "abc"}).encode()).decode(),
)
~~~

`invocation.invoke_async` queues the call and returns its id at once. Read the
result later with `invocation.get`.

## Async usage

The async client exposes the same groups and methods.

~~~python
import asyncio
import os

from alchemy import AsyncAlchemy

async def main():
    alchemy = AsyncAlchemy(
        base_url=os.getenv("ALCHEMY_URL", "http://localhost:8780"),
        token=os.getenv("ALCHEMY_TOKEN", "local"),
    )
    response = await alchemy.function.list()
    for function in response.functions or []:
        print(function.id, function.name)

asyncio.run(main())
~~~

## API groups

| Group | Methods |
| --- | --- |
| `function` | `create`, `get`, `list`, `update`, `delete`, `invoke` |
| `function.version` | `create`, `get`, `list` |
| `invocation` | `invoke`, `invoke_async`, `get`, `list` |
| `runtime` | `list` |
| `template` | `list` |
| `host` | `get`, `list` |
| `instance` | `list` |
| `metrics` | `query_timeseries`, `query_aggregate`, `get_queue` |
| `auth` | `get_config`, `get_session`, `login`, `logout` |
| `member` | `list`, `invite`, `set_role`, `remove` |
| `service_account` | `create`, `list`, `rotate_secret`, `remove` |

`alchemy.get_version(request={})` reports the server's build. Methods whose request message has no fields take an empty `request`.

The SDK covers unary API methods. The streaming `GetInvocationLogs` and
`TailInvocations` are not included.

## Responses

Methods return generated models. For example, `function.create(...)` returns a
response whose `function` property holds the created function.

Fields the server omits can be `None`, including lists. Use
`response.functions or []` when iterating. Protobuf 64-bit integer fields, such
as version numbers and timestamps, can be decimal strings. Use `int(value)`
when needed.

## Errors and retries

~~~python
from alchemy.core.api_error import ApiError

try:
    alchemy.function.get(id="missing-function")
except ApiError as error:
    print(error.status_code)
    print(error.body)
~~~

Automatic retries are disabled because mutations and invokes are not generally
idempotent. For a read you want to retry, use
`alchemy.function.list(request_options={"max_retries": 2})`.

## Development

The client and models are generated by Fern from the OpenAPI specification
that Buf derives from the protos. CI generates them. When the specification or
`fern/` changes on `main`, a workflow opens a pull request with the new
`sdks/python/src/alchemy/`. Do not edit or commit that directory by hand.
Configure names and generation in `fern/`. This README and the package
metadata are maintained by hand and survive regeneration.

To build the wheel and source distribution from the repository root:

~~~sh
uv build --no-sources --project sdks/python
~~~
