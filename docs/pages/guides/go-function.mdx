A Go function is a static binary that reads its input on stdin and writes its
output on stdout. Alchemy runs it two ways:

- **From source.** You send `main.go`. A host compiles it in a microVM on the
  `go:1.27-build` image and the version runs the binary on `go:1.27`.
- **As an image.** You compile the binary yourself and copy it into an image
  on `static:13`.

The commands assume a server on `localhost:8780` with no auth, as in the
[Quickstart](/pages/get-started/quickstart). With auth enabled, add
`-H "Authorization: Bearer $TOKEN"` to every call.

## The Go runtime

| Image | What it is |
|---|---|
| `<imagePrefix>/go:1.27` | Distroless static Debian 13 that runs `/app/handler` |
| `<imagePrefix>/go:1.27-build` | `golang:1.27-alpine` with the module's dependencies downloaded and compiled |
| `<imagePrefix>/static:13` | The same distroless base, for binaries built elsewhere |

The default prefix is `ghcr.io/galaxy-io/alchemy/runtime`, set by the server's
`RUNTIME_IMAGE_PREFIX`. Ask the server for the exact image:

```sh
curl -s localhost:8780/functions.v1.FunctionsService/ListRuntimes \
  -H 'Content-Type: application/json' -d '{}' \
  | jq -r '.runtimes[] | select(.id == "go") | .image'
```

Compiles run offline. Your files land in a module named `handler` whose only
requirement is `github.com/apache/arrow-go/v18` v18.8.0, so a source can
import the standard library and Arrow, nothing else. A function with other
dependencies ships as an [image](#deploy-as-an-image).

## The protocol

For each invocation the supervisor starts `/app/handler` as a new process,
writes the input to stdin and closes it, takes stdout as the output and
streams stderr to the invocation's log. A non-zero exit is a crash, reported
with the exit status and the last 4 KiB of stderr. A JSON Schema contract
passes one JSON value each way, an Arrow contract one IPC stream with exactly
one record batch. See [Contracts](/pages/concepts/contracts).

## Write a handler

The runtime's JSON Schema starter:

```go main.go
package main

import (
	"encoding/json"
	"fmt"
	"os"
)

func handler(event any) (any, error) {
	return event, nil
}

func main() {
	var event any
	if err := json.NewDecoder(os.Stdin).Decode(&event); err != nil {
		fail(err)
	}
	out, err := handler(event)
	if err != nil {
		fail(err)
	}
	if err := json.NewEncoder(os.Stdout).Encode(out); err != nil {
		fail(err)
	}
}

func fail(err error) {
	fmt.Fprintln(os.Stderr, err)
	os.Exit(1)
}
```

For an Arrow contract, read with `ipc.NewReader(os.Stdin)`, take one record
batch, and write one batch with the same number of rows through
`ipc.NewWriter(os.Stdout, ...)`. This handler reads `id` and `text` columns
and returns the cleaned text, its token count and a 64-dimension embedding
per row. It uses the same Arrow version as the runtime, so it compiles as a
source unchanged:

```go main.go
package main

import (
	"fmt"
	"math"
	"os"
	"strings"

	"github.com/apache/arrow-go/v18/arrow"
	"github.com/apache/arrow-go/v18/arrow/array"
	"github.com/apache/arrow-go/v18/arrow/ipc"
	"github.com/apache/arrow-go/v18/arrow/memory"
)

const (
	dimensions = 64
	model      = "hash-trigram-64-v1"
)

var output = arrow.NewSchema([]arrow.Field{
	{Name: "id", Type: arrow.BinaryTypes.String},
	{Name: "cleaned_text", Type: arrow.BinaryTypes.String},
	{Name: "token_count", Type: arrow.PrimitiveTypes.Uint32},
	{Name: "embedding", Type: arrow.FixedSizeListOf(dimensions, arrow.PrimitiveTypes.Float64)},
	{Name: "model", Type: arrow.BinaryTypes.String},
}, nil)

func handler(in arrow.RecordBatch) arrow.RecordBatch {
	ids := in.Column(0).(*array.String)
	texts := in.Column(1).(*array.String)
	b := array.NewRecordBuilder(memory.DefaultAllocator, output)
	defer b.Release()
	embeddings := b.Field(3).(*array.FixedSizeListBuilder)
	for i := range int(in.NumRows()) {
		tokens := strings.Fields(strings.ToLower(texts.Value(i)))
		b.Field(0).(*array.StringBuilder).Append(ids.Value(i))
		b.Field(1).(*array.StringBuilder).Append(strings.Join(tokens, " "))
		b.Field(2).(*array.Uint32Builder).Append(uint32(len(tokens)))
		embeddings.Append(true)
		embeddings.ValueBuilder().(*array.Float64Builder).AppendValues(embed(tokens), nil)
		b.Field(4).(*array.StringBuilder).Append(model)
	}
	return b.NewRecordBatch()
}

func fnv1a(bytes []byte) uint32 {
	h := uint32(2166136261)
	for _, c := range bytes {
		h = (h ^ uint32(c)) * 16777619
	}
	return h
}

func embed(tokens []string) []float64 {
	v := make([]float64, dimensions)
	for _, token := range tokens {
		padded := []byte("<" + token + ">")
		for i := 0; i+3 <= len(padded); i++ {
			h := fnv1a(padded[i : i+3])
			if h&0x80000000 == 0 {
				v[h%dimensions]++
			} else {
				v[h%dimensions]--
			}
		}
	}
	var sum float64
	for _, x := range v {
		sum += x * x
	}
	if norm := math.Sqrt(sum); norm > 0 {
		for i := range v {
			v[i] /= norm
		}
	}
	return v
}

func main() {
	reader, err := ipc.NewReader(os.Stdin)
	if err != nil {
		fail(err)
	}
	defer reader.Release()
	if !reader.Next() {
		fail(fmt.Errorf("input holds no record batch: %v", reader.Err()))
	}
	out := handler(reader.RecordBatch())
	defer out.Release()
	w := ipc.NewWriter(os.Stdout, ipc.WithSchema(out.Schema()))
	if err := w.Write(out); err != nil {
		fail(err)
	}
	if err := w.Close(); err != nil {
		fail(err)
	}
}

func fail(err error) {
	fmt.Fprintln(os.Stderr, err)
	os.Exit(1)
}
```

The Arrow contract's schemas are serialized Arrow IPC. Build them as in the
[Python guide](/pages/guides/python-function), which writes `arrow.json` for
the same handler, or define the fields in the web UI.

## Deploy from source

A source version names `go:1.27` as its image and carries `main.go`. When the
version builds, the server sees that the image has a build image and compiles
first:

1. The least busy host boots `go:1.27-build` in a microVM of its own, with
   2 vCPUs and 2 GiB, or the host's whole memory budget when that is smaller.
2. The build image copies your files into the module and runs
   `go build -ldflags='-s -w'`. The compiler's output is the build log.
3. The host stores the binary as a layer in the artifacts bucket, and the
   version is built from `go:1.27` with that layer at `/app/handler`.

A compile has 3 minutes. Its result is kept by the build image's digest and
the source's, so the same files on the same build image compile once. A
republished build image compiles afresh. The version's spec
keeps your source, which `GetFunctionVersion` returns.

<Steps>
  <Step title="Create the function">
    <CodeGroup>
    ```text Web UI
    1. Click New function.
    2. Choose Code and pick Go 1.27 as the language.
    3. Define the contract.
    4. Replace the starter with your main.go.
    5. Set resources and limits, name the function and click
       Create function.
    ```

    ```sh API
    IMAGE=$(curl -s localhost:8780/functions.v1.FunctionsService/ListRuntimes \
      -H 'Content-Type: application/json' -d '{}' \
      | jq -r '.runtimes[] | select(.id == "go") | .image')

    jq -n --arg image "$IMAGE" --rawfile src main.go --slurpfile arrow arrow.json '{
      name: "embed-go",
      spec: {
        image: $image,
        protocol: "INVOCATION_PROTOCOL_EXEC",
        contract: {arrow: $arrow[0]},
        source: {files: [{path: "main.go", content: ($src | @base64)}]}
      }
    }' | curl -s localhost:8780/functions.v1.FunctionsService/CreateFunction \
      -H 'Content-Type: application/json' -d @- | jq '{id: .function.id, status: .version.status}'
    ```
    </CodeGroup>

    Send `.go` files only. A `go.mod` or `go.sum` you send replaces the
    module's, and any requirement the build image has not downloaded fails
    the offline build.
  </Step>
  <Step title="Wait for the build">
    ```sh
    curl -s localhost:8780/functions.v1.FunctionsService/GetFunctionVersion \
      -H 'Content-Type: application/json' \
      -d '{"functionId": "<function-id>", "version": 1}' \
      | jq -r '.version | .status, .statusMessage, .buildLog'
    ```

    A compile error fails the version. `statusMessage` starts with
    `compile failed:` and `buildLog` holds the compiler's output.
  </Step>
</Steps>

<Warning>
  Only the exact image `ListRuntimes` returns is compiled. A source on any
  other reference to a Go runtime, such as the public `ghcr.io` image on a
  server whose prefix points elsewhere, is laid over the image uncompiled,
  and every invocation crashes because `/app/handler` does not exist.
</Warning>

## Deploy as an image

Build the binary yourself when it needs other modules or build flags. This
Dockerfile compiles your module, with its `go.mod` and `go.sum`, in one stage
and copies the binary onto `static:13`:

```dockerfile Dockerfile
FROM golang:1.26-alpine AS build
WORKDIR /src
COPY go.mod go.sum main.go ./
RUN CGO_ENABLED=0 go build -trimpath -o /out/handler .

FROM ghcr.io/galaxy-io/alchemy/runtime/static:13
COPY --from=build /out/handler /app/handler
```

`static:13` has no libc, so build with `CGO_ENABLED=0`. From the module's
directory, build for the hosts' architecture and push:

```sh
docker build --platform linux/amd64 -t registry.example.com/embed-go:1 .
docker push registry.example.com/embed-go:1
```

Create the function with that image and no `source`:

```sh
jq -n --slurpfile arrow arrow.json '{
  name: "embed-go",
  spec: {
    image: "registry.example.com/embed-go:1",
    protocol: "INVOCATION_PROTOCOL_EXEC",
    contract: {arrow: $arrow[0]}
  }
}' | curl -s localhost:8780/functions.v1.FunctionsService/CreateFunction \
  -H 'Content-Type: application/json' -d @- | jq '{id: .function.id, status: .version.status}'
```

See [Deploy any OCI image](/pages/guides/image-function) for private
registries.

## Invoke it

POST the input with the contract's content type. For the Arrow handler,
write `input.arrows` as in the [Python guide](/pages/guides/python-function):

```sh
curl -s localhost:8780/functions/<function-id>/invoke \
  -H 'Content-Type: application/vnd.apache.arrow.stream' \
  --data-binary @input.arrows -o output.arrows
```

For a JSON contract, send `-H 'Content-Type: application/json'` and the value
with `-d`. The response carries `Alchemy-Invocation-Id` and `Alchemy-Version`.
A handler that exits non-zero answers `500`, and one past its timeout `504`.
See [HTTP invoke](/pages/usage/http).
