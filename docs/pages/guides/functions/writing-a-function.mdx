---
title: "Writing a function"
description: "Package a handler as an Alchemy function."
---

A function is an OCI image whose entrypoint reads its input on stdin and writes its output on stdout. On a runtime image, a Python or TypeScript function is a handler and a two line Dockerfile.

```dockerfile
FROM ghcr.io/galaxy-io/alchemy/runtime/python:3.13
COPY handler.py /app/
```

A function on a runtime image needs no image of its own. A version whose spec carries `source` files, such as `handler.py`, is built from them: Alchemy keeps the files in its artifacts bucket and lays them over the runtime at `/app`.
