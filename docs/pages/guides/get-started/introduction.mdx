---

Alchemy is a runtime for fast, isolated, strongly typed compute functions, built by [Galaxy](https://www.getgalaxy.io). It runs each invocation in its own Firecracker microVM, checks every input and output against the function's contract, and records the full lifecycle of every call.

A function is an OCI image plus a contract. Alchemy builds it into a root filesystem once and boots it on demand. Run Alchemy as a service with its API and web UI, or deploy it to your own machines with KVM.
