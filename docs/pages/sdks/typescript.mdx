`@galaxy-io/alchemy-ts` is the generated TypeScript client for Alchemy's API.
It ships as ES modules with type declarations, has no runtime dependencies, and
runs on Node 18 or newer or any runtime with `fetch`.

## Installation

<CodeGroup>

```sh npm
npm install @galaxy-io/alchemy-ts
```

```sh pnpm
pnpm add @galaxy-io/alchemy-ts
```

```sh yarn
yarn add @galaxy-io/alchemy-ts
```

```sh bun
bun add @galaxy-io/alchemy-ts
```

</CodeGroup>

## Connect

```ts
import { AlchemyClient } from "@galaxy-io/alchemy-ts";

const alchemy = new AlchemyClient({
  baseUrl: process.env.ALCHEMY_URL ?? "http://localhost:8780",
  auth: false,
});

const { functions } = await alchemy.function.list({});
for (const fn of functions ?? []) {
  console.log(fn.id, fn.name);
}
```

This connects to a server with authentication disabled. See
[Authentication](#authentication) for a deployed server. Request timeouts are
set with `timeoutInSeconds` and retries with `maxRetries`, on the client or per
call. The client retries twice by default, so pass `maxRetries: 0` on calls
that must not repeat, such as an invoke without an idempotency key.

## Authentication

When the server runs with an [identity provider](/pages/deployment/authentication),
the SDK authenticates as a service account. Create one with
`alchemy.serviceAccount.create(...)` while signed in as an admin. It returns a
client id and a client secret, and the secret is shown once.

Pass them to the client. It mints an access token through the server and mints
again as the token nears expiry.

```ts
const alchemy = new AlchemyClient({
  baseUrl: process.env.ALCHEMY_URL ?? "http://localhost:8780",
  clientId: process.env.ALCHEMY_CLIENT_ID!,
  clientSecret: process.env.ALCHEMY_CLIENT_SECRET!,
});
```

A token minted elsewhere works as `token`. For a local server with
authentication disabled, pass `auth: false`. The client refuses to construct
without one of the three.

## Invoke a function

`function.invoke` is the [plain HTTP route](/pages/usage/http). It sends the
input as JSON and resolves to the output with no envelope, so it fits functions
with a JSON Schema contract.

```ts
const output = await alchemy.function.invoke({
  function: "<function-id>",
  body: { id: "abc" },
});
```

`invocation.invoke` is the RPC form. It resolves to the invocation with its
id, status and error, and it carries the input and output as base64, which is
how an Arrow contract's IPC stream travels over JSON.

`invocation.invokeAsync` queues the call and resolves to its id at once. Read
the result later with `invocation.get`.

## API groups

| Group | Methods |
| --- | --- |
| `function` | `create`, `get`, `list`, `update`, `delete`, `invoke` |
| `function.version` | `create`, `get`, `list` |
| `invocation` | `invoke`, `invokeAsync`, `get`, `list` |
| `runtime` | `list` |
| `template` | `list` |
| `host` | `get`, `list` |
| `instance` | `list` |
| `metrics` | `queryTimeseries`, `queryAggregate`, `getQueue` |
| `auth` | `getConfig`, `getSession`, `login`, `logout` |
| `member` | `list`, `invite`, `setRole`, `remove` |
| `serviceAccount` | `create`, `list`, `rotateSecret`, `remove` |

`alchemy.getVersion({})` reports the server's build.

The SDK covers unary API methods. The streaming `GetInvocationLogs` and
`TailInvocations` are not included. Read logs with the
[CLI](/pages/usage/cli).

## Responses and errors

Methods resolve to typed responses. `function.create(...)` resolves to an
object whose `function` property holds the created function.

Fields the server omits are `undefined`, including lists, so iterate with
`response.functions ?? []`. Protobuf 64-bit integer fields, such as version
numbers and timestamps, can be decimal strings. Use `Number(value)` or
`BigInt(value)` when needed.

Errors are thrown as `AlchemyError`, with `statusCode` and the server's
message. Timeouts throw `AlchemyTimeoutError`.
